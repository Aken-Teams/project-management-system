範例：R 三筆工作報告 → A 彙整為一份正式報告

任務「需求訪談」由 R 執行、A 當責。走一遍完整流程。
R 負責
訪談紀錄 ①7/8
訪談紀錄 ②7/9
訪談紀錄 ③7/10
→
提交 · 通知 A
A 當責
於撰寫台匯入 3 筆 → 彙整
正式報告（1 份）
A 彙整三筆訪談內容，撰寫為一段報告，填報告日期。
→
送出本週報告
系統
✓更新紀錄呈現 A 的報告
✓任務進度依報告日期更新
✓甘特圖同步更新
R 的三筆紀錄作為 參考資料，不單獨列於更新紀錄。
重點：R 提交三筆訪談紀錄；A 匯入後彙整為一份正式報告並送出。
進度、更新紀錄、甘特圖以 A 送出的正式報告為準；R 的原始紀錄供 A 參考，不會各自列出。
＊示意圖，可截圖插入《流程說明》3.3 範例。
