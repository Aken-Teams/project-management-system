里程碑階段總覽 — 狀態說明

給主管看

總覽有三列：階段（依里程碑狀態上色）、Plan（規劃時程，外框）、Actual（實際 = 完成度% × 規劃區間，端點對比「今天線」判讀落後/超前）。以下說明每個狀態何時觸發、長什麼樣。

1階段 / Plan 列 — 依里程碑狀態上色

「階段」與「Plan」兩列的顏色，看該里程碑本身的狀態（跟底下任務一致）。

呈現狀態觸發條件
P1 已完成已完成里程碑進度 100%、狀態＝完成。
P3 進行中進行中有進度（>0%）且尚未完成。
P4 逾期逾期尚未完成、且今天已超過規劃截止日。
P5 未開始未開始進度 0%、尚未動工。

2Actual 列 — 完成度長條（earned value）

Actual 長度＝完成度% × 規劃區間（把「做了多少」映射到時間軸）。長條端點落在今天線的哪一邊，決定落後/超前；已完成則看是否晚於規劃截止（遲交）。

呈現（Plan 外框 · Actual 實際 · │今天）狀態觸發條件
今天
落後進行中，完成度長條端點在今天線左邊（該做到今天的量、實際還沒到）。缺口用琥珀斜線補到今天。tooltip 顯示「落後約 N 天」。
今天
超前進行中，完成度長條端點超過今天線（比進度該有的還多）。超出今天的那段用綠色斜線。tooltip 顯示「超前約 N 天」。
今天
遲交已完成，但實際完成日晚於規劃截止日。綠條畫滿規劃區間，超出截止的那段用紅色斜線＋「遲 N 天」。→ 100% 後仍看得出當初卡住/逾期。
今天
準時完成已完成、且未晚於規劃截止 → 整段實心綠（例：P1、P2）。P3 若做到 100% 也會變這樣。
今天
未開始完成度 0% → Actual 不畫（例：P5）。

3特殊標記與整體

呈現項目觸發條件
⚠P3 瓶頸瓶頸（最落後）所有未完成階段中，earned 落後今天最多的那一段。只加紅色 ⚠，不改階段本身的狀態色（進行中仍是藍，與其任務一致）。
今天今天線紅色直線標示今天，用來對比 Actual 是落後或超前。
落後約 56 天整體時程健康徽章（標題列）比較整體實際完成% vs 依今天時間軸應達%：
實際<應達 → 落後約 N 天
超前約 N 天實際>應達 → 超前約 N 天
準時兩者相當 → 準時

4互動（給主管快速聚焦）

操作效果
點某階段（階段/Plan/Actual 任一）聚焦：該階段在三列維持明亮、其餘變淡；再點一次或點其他階段取消/切換。
Hover 一般階段簡版提示：名稱 · 規劃期間 · 狀態·進度%。
Hover 已聚焦的階段詳版提示：進度條 · ⚠瓶頸 · 規劃期間 · 落後/超前約 N 天 · 截止倒數/已逾期（＋遲交資訊）。
提醒：hover 提示在「點擊選取」當下會被關閉（元件正常行為），聚焦後要把滑鼠移開再移回該階段，才會看到詳版提示。
