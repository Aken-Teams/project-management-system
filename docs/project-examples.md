## 1. NPI 新產品開發：智慧健康手環 V2.0

### 基本資訊

| 欄位 | 內容 |
|------|------|
| **專案名稱** | 智慧健康手環 V2.0 開發專案 |
| **專案類型** | NPI-新產品開發 (`npi`) |
| **專案層級** | T1 |
| **需求來源** | 公司政策/年度目標 (`company-policy`) |
| **起始日期** | 2026-03-01 |
| **結束日期** | 2026-07-31（約 22 週）|
| **預算** | NT$ 3,500,000 |

### 專案定義

**目標：**
開發新一代智慧健康手環，整合血氧監測、心率變異性分析及睡眠品質追蹤功能，目標 Q3 上市

**用途：**
擴展穿戴裝置產品線，提升品牌在健康監測市場的競爭力

**範圍：**
硬體設計（感測器整合、電路設計）、韌體開發、App 介面改版、供應鏈建立、量產導入

**ROI：**
預期第一年銷售 50,000 支，營收 NT$ 75,000,000，ROI 約 2,143%

**建立原因：**
現有產品功能老化，市場競品已具備血氧監測，需升級以保持市佔率

**預期效益：**
增加 15% 市佔率、提升品牌形象、建立健康監測技術門檻

### SMART 目標

- **Specific（具體）：** 開發搭載 SpO2 血氧感測器、HRV 演算法的智慧手環，支援 iOS/Android App
- **Measurable（可衡量）：** 血氧精準度 ±2%、電池續航 ≥7 天、量產良率 ≥95%、Q3 上市
- **Achievable（可達成）：** 已有前代產品經驗，供應商資源充足，研發團隊具備相關技術能力
- **Relevant（相關性）：** 符合公司年度策略「強化健康科技產品線」，回應市場對健康監測的需求
- **Time-bound（時限）：** 2026/3/1 啟動，2026/7/31 完成量產導入，Q3 正式上市

## 2. 製程優化：SMT 貼片良率提升專案

### 基本資訊

| 欄位 | 內容 |
|------|------|
| **專案名稱** | SMT 貼片製程良率提升專案 |
| **專案類型** | 製程優化 (`process-optimization`) |
| **專案層級** | T2 |
| **需求來源** | 內部需求 (`internal-demand`) |
| **起始日期** | 2026-02-20 |
| **結束日期** | 2026-05-15（約 12 週）|
| **預算** | NT$ 800,000 |

### 專案定義

**目標：**
將 SMT 貼片良率從目前 92% 提升至 97% 以上，降低返工成本

**用途：**
優化 SMT 製程參數、設備保養制度、人員操作標準，提升產線效率

**範圍：**
印刷製程、貼片精度、回焊溫度曲線、AOI 檢測標準、SOP 更新

**ROI：**
良率提升 5% = 每月減少 10,000 pcs 返工，節省成本 NT$ 200,000/月，年省 NT$ 2,400,000，ROI 300%

**建立原因：**
近 3 個月良率下滑趨勢明顯（從 95% → 92%），客訴增加，影響交期

**預期效益：**
良率達 97%、返工工時減少 40%、客訴率降低 50%、製程能力指數 Cpk ≥ 1.67

### SMART 目標

- **Specific（具體）：** 優化 SMT 印刷、貼片、回焊三大製程，建立標準化 SOP，導入預防保養制度
- **Measurable（可衡量）：** 良率從 92% → 97%、錫膏印刷偏移 ≤ 0.05mm、回焊後冷焊率 ≤ 0.5%
- **Achievable（可達成）：** 已識別關鍵問題（印刷機刮刀磨損、回焊溫度曲線不穩），設備廠商可提供技術支援
- **Relevant（相關性）：** 符合公司品質政策「追求零缺陷」，回應客戶品質要求提升
- **Time-bound（時限）：** 2026/2/20 啟動，2026/5/15 完成改善並標準化，第 12 週達成 97% 良率目標

## 3. 自動化：智慧倉儲管理系統（WMS）

### 基本資訊

| 欄位 | 內容 |
|------|------|
| **專案名稱** | 智慧倉儲管理系統導入專案 |
| **專案類型** | 自動化 (`automation`) |
| **專案層級** | T1 |
| **需求來源** | 公司政策/年度目標 (`company-policy`) |
| **起始日期** | 2026-04-01 |
| **結束日期** | 2026-07-15（約 15 週）|
| **預算** | NT$ 2,800,000 |

### 專案定義

**目標：**
導入智慧倉儲管理系統（WMS + AGV + RFID），取代人工倉管作業，提升出入庫效率 60%

**用途：**
自動化倉儲物料進出管理、即時庫存盤點、先進先出控制、與 ERP 系統整合

**範圍：**
WMS 軟體開發/導入、RFID 標籤系統、AGV 無人搬運車（2 台）、倉儲貨架改造、人員培訓

**ROI：**
人力節省 4 人（年薪 NT$ 400,000/人），出貨速度提升 60%，庫存準確率 99%，年效益 NT$ 1,600,000，ROI 57%

**建立原因：**
現有倉儲採人工記錄，常發生帳實不符、先進後出、找料耗時，影響生產排程

**預期效益：**
出入庫時間從 30 分鐘 → 10 分鐘、庫存準確率 85% → 99%、人力成本減少 50%

### SMART 目標

- **Specific（具體）：** 導入 WMS 軟體、建置 RFID 感應門、部署 2 台 AGV、改造倉儲貨架編碼系統
- **Measurable（可衡量）：** 出入庫效率提升 60%、庫存準確率 ≥ 99%、找料時間 ≤ 5 分鐘、AGV 稼動率 ≥ 80%
- **Achievable（可達成）：** 已評估 3 家 WMS 廠商，倉儲空間足夠（200 坪），預算已核准
- **Relevant（相關性）：** 符合公司數位轉型策略，支援業務成長（訂單量年增 30%）
- **Time-bound（時限）：** 2026/4/1 啟動，2026/7/15 正式上線，第 8 週完成系統測試

1. 在「SMT 良率提升」專案中，移除「吳佳玲」（設備工程師離職）
2. 新增「陳志豪」替代，角色：工程師，職責：印刷機/貼片機校正
3. 將原本指派給吳佳玲的任務重新指派給陳志豪

**場景四：週報提交與進度追蹤**
1. 在「智慧健康手環 V2.0」專案中，每週提交週報
2. 更新每個里程碑的進度百分比
3. 填寫「本週關鍵成就」「下週計畫」「阻礙事項」
4. 系統自動計算專案整體進度

### 4. 資料輸入技巧

**快速建立專案流程：**
1. 複製本文檔中的「基本資訊」→ 貼到建立專案表單
2. 複製「SMART 目標」五個欄位 → 逐一貼到對應欄位
3. 使用「團隊成員」表格 → 逐一新增成員（系統會自動建立使用者）
4. 複製「里程碑名稱」→ 系統自動帶入模板（手動調整週數）
5. 在每個里程碑下新增任務（從「任務列表」複製標題）
6. 複製「風險管理」表格 → 逐一新增風險項目

**注意事項：**
- 專案層級選擇：T1（重要戰略）、T2（中等重要）、T3（一般改善）、CIP（持續改善）
- 日期格式：使用 `YYYY-MM-DD` 格式（例如：`2026-03-01`）
- 預算金額：輸入數字即可（例如：`3500000`），系統會自動格式化
- 角色代碼：務必使用括號內的英文代碼（例如：`pm`、`engineer`、`qa`）
- 優先度：`low`（低）、`medium`（中）、`high`（高）

### 5. 驗證檢查清單

建立專案後，請檢查以下項目：

- [ ] 專案基本資訊完整（名稱、類型、層級、日期、預算）
- [ ] SMART 目標五個欄位都已填寫
- [ ] 專案定義（目標、用途、範圍、ROI、建立原因、預期效益）
- [ ] 團隊成員至少 4 人，角色分配合理
- [ ] 里程碑數量符合專案類型（4-6 個）
- [ ] 每個里程碑下至少有 3 個任務
- [ ] 所有任務都有指派人、優先度、起訖日期
- [ ] 風險項目至少 3 個，包含影響、機率、緩解措施
- [ ] 專案編號自動產生（例如：`NPI-2026-001`）
- [ ] 任務相依性自動建立（順序鏈接）
- [ ] 基線快照自動建立
