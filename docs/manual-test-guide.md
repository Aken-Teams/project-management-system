## 🆕 本次大改動驗證（ADR-01 絕對日期 / ADR-02 六層 / 拖曳 / 存檔）

> 這些是 2026-07-07 大量重構的功能，**新增 + 編輯專案都要各測一次**。

### A. 絕對日期 + 拔除依序（ADR-01）
- [ ] **A1 改一列不動別列**：改某任務的天數或日期 → 只有它的結束日變，**上下其他里程碑/任務都不動**。
- [ ] **A2 start+天數→end**：填開始 7/1、天數 10 → 結束自動帶 7/10；反填結束 → 天數自動反算。
- [ ] **A3 里程碑完全手動**：有任務的里程碑也能直接改日期；改了不連動任務。
- [ ] **A4 改「專案開始日」**：里程碑**不會**自動整批移動（絕對模式）。若覺得建案時不便回報。
- [ ] **A5 鎖按鈕已移除**：里程碑/任務列**看不到**「🔒自動/手動」。

### B. 六層巢狀（ADR-02）
- [ ] **B1 建深層**：對任務按「＋新增子項」一路建到**第 6 層**（里程碑=1 + 任務 5 層）→ 縮排正確、第 6 層**沒有**再往下的「新增子項/縮排」鈕。
- [ ] **B2 按鈕階梯**：子任務「升階」→ 任務；任務「縮排」→ 上一列子項、「升階」→ 里程碑；里程碑「降為任務」→ 併入相鄰里程碑。各深度都可用。
- [ ] **B3 拖曳巢狀**：把任務拖進另一任務中間 → 變子項（任意深度）；超過 6 層應被擋（目前**無提示**，是已知小問題）。
- [ ] **B4 深層進度滾動** ⭐：在**最深的葉子**標完成/寫日誌 → 進度應一路往上滾：葉→父→…→里程碑。連續重整**穩定**。
- [ ] **B5 存深層** ⭐（最重要）：建立/編輯一棵 4~6 層的樹 → 存檔 → **重開專案** → 深層結構、指派、進度**都還在**、不重複、不遺失。
- [ ] **B6 刪深層父項**：刪一個有子孫的中層任務 → 存檔 → 整棵子樹一起消失、**存檔不報錯**（防了 cascade 404）。

### C. 存檔不關（編輯專案）
- [ ] **C1 存後不關**：編輯 → 儲存變更 → 跳「**儲存變更完成**」提示、**視窗不關**。
- [ ] **C2 連續存不重複** ⭐：改→存→再改→再存（不關窗）→ 重開專案確認**沒有重複**的里程碑/任務。

### D. 甘特圖
- [ ] **D1 預設全展開**：開甘特預覽 → 所有里程碑 + 所有有子項的任務**一開就全攤開**，不用一個一個點。
- [ ] **D2 深層都畫得出**：第 3~6 層的任務在甘特上都有長條、依深度縮排。
- [ ] **D3 里程碑長條 = 自身日期**：里程碑長條的範圍應與**表格顯示的里程碑起訖日一致**（不再是任務 envelope）。
- [ ] **D4 無任務里程碑有長條**：沒有任務的里程碑也畫得出完整長條（不是細線）。
- [ ] **D5 tooltip 貼游標**：hover 里程碑/任務長條 → tooltip 貼在游標上（不會跑到很遠）。

### E. 其他
- [ ] **E1 AI 輔助建立已隱藏**：進「建立新專案」直接是手動表單、**沒有 AI 分頁**。
- [ ] **E2 收合記憶**：里程碑預設全收合；展開幾個後刷新/重開 → 狀態維持（依專案各自記）。
